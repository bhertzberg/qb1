# qb1

Static birthday microsite for `Quarter Bentury` at `The Land`.

## Files

- `index.html`: animated intro screen with the cabin door entry interaction
- `styles.css`: intro screen styling, responsive doorway layout, and transitions
- `script.js`: door-open timing and reveal sequencing
- `main.html`: the main event landing page content
- `main.css`: styling for the main event landing page
- `assets/ben-head.png`: dog portrait used in the intro window

## Local preview

Open `index.html` directly in a browser, or serve the folder with any static file server.

## Customize next

- Replace the placeholder date, address, and RSVP details in `main.html`
- Add real shared album / photo upload links
- Swap in any final event copy, FAQ items, or schedule details
